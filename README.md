# Gloria UWASE Portfolio

## Requirements

- Node.js 18 or newer
- npm

## Run locally

From this folder, install dependencies and start the Vite development server:

```powershell
npm install
npm run dev
```

Open the URL shown in the terminal, usually `http://localhost:5173`.

## Verify a production build

```powershell
npm run build
npm run preview
```

The preview command serves the generated `dist` folder.

## Demo admin login

Open `/login` and enter any non-empty email and password. This is a browser-only demo; it does not provide production authentication.
